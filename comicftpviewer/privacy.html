← FTP 만화 뷰어

개인정보처리방침

시행일: 2026년 10월 17일

"FTP 만화 뷰어"(이하 "앱")는 사용자가 지정한 FTP 서버의 만화를 보는 안드로이드 앱입니다. 앱 개발자는 사용자의 개인정보를 수집하거나 전송하거나 보관하지 않습니다. 이 문서는 앱이 어떤 정보를 어디에 저장하는지 설명합니다.

1. 기기 안에만 저장되는 정보

  • 사용자가 입력한 FTP 서버 정보(주소, 포트, 아이디, 비밀번호). 비밀번호는 안드로이드 Keystore 키로 암호화해 저장합니다.
  • 읽던 위치, 최근 본 만화 목록, 메모·책갈피, 즐겨찾기 폴더, 숨긴 항목 설정
  • 빠르게 보기 위한 페이지 캐시, 사용자가 받은 만화 파일(사용자가 고른 폴더)

이 정보는 앱을 삭제하거나 앱 설정에서 지우면 기기에서 사라집니다. 개발자에게 전송되지 않습니다.

2. FTP 서버와의 통신

앱은 사용자가 입력한 FTP 서버에만 직접 연결해 목록과 이미지를 받습니다. 그 외의 서버로 만화나 기록을 보내지 않습니다. 일반 FTP는 아이디·비밀번호와 파일이 암호화되지 않고 전송되므로, 공용 와이파이에서는 사용하지 않기를 권합니다.

3. 기기 간 동기화 (선택, 구글 계정)

설정에서 "기기 간 동기화"를 켜고 구글 계정으로 로그인한 경우에만 다음과 같이 동작합니다.

  • 앱은 Google Drive의 앱 전용 폴더(drive.appdata) 권한만 요청합니다. 이 폴더는 사용자의 드라이브 화면에 보이지 않으며, 앱은 사용자의 다른 드라이브 파일을 보거나 바꿀 수 없습니다.
  • 이 폴더에 기기별 기록 파일을 저장합니다: 서버 목록(비밀번호 제외), 읽던 위치와 보기 방식, 최근 본 목록, 메모·책갈피, 즐겨찾기, 숨긴 항목 목록과 숨김 비밀번호의 해시값.
  • 기록은 사용자 본인의 Google Drive에만 저장되며, 개발자를 포함한 다른 사람은 볼 수 없습니다.
  • FTP 서버 비밀번호는 동기화하지 않습니다.
  • 로그인한 구글 계정의 이메일 주소는 설정 화면에 "어느 계정으로 동기화 중인지" 보여 주는 데만 쓰고, 기기 밖으로 보내지 않습니다.

앱의 Google API 사용과 Google API에서 받은 정보의 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 동기화 끄기와 기록 삭제

  • 앱 설정의 "동기화 끄기"로 이 기기의 동기화를 멈출 수 있습니다.
  • 구글 계정 설정의 "보안 → 타사 앱 연결"에서 이 앱의 권한을 해제할 수 있습니다.
  • 드라이브에 저장된 기록은 Google Drive 웹의 "설정 → 앱 관리"에서 이 앱의 "숨겨진 앱 데이터 삭제"로 지울 수 있습니다.

5. 제3자 제공, 광고, 분석

앱은 개인정보를 제3자에게 제공하지 않으며, 광고나 사용 통계(분석) 도구를 포함하지 않습니다.
